# GLOSSARY.md format

Canonical language for this workspace. Add a term only when the user can use it correctly.

```md
# {Topic} Glossary

{One or two sentences on scope.}

## Terms

**Term**:
One- or two-sentence definition of what it IS.
_Avoid_: aliases you will not use
```

- Opinionated: pick one word, list the rest as avoid.
- Use glossary terms inside later definitions.
- Revise in place as understanding deepens.
