# Learning record format

`reports/teach/<slug>/learning-records/NNNN-slug.md` — increment the highest existing number.

```md
# {Short title}

{1–3 sentences: what is now known, and why that changes the next lesson.}
```

Write when: demonstrated understanding, disclosed prior knowledge (with claimed depth), a misconception was corrected, or the mission shifted.

Do **not** write for mere coverage, glossary duplicates, or session diaries.

If a later record contradicts an earlier one, mark the old one `Status: superseded by LR-NNNN` — do not delete it.
