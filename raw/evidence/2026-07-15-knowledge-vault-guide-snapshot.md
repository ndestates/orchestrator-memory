## Summary of vault role

The orchestrator template maintains a **secure self-building knowledge vault**: append-only, content-hashed events in `reports/vault/events.jsonl` with scrubbing, provenance, and verification on compound.

## Learning pipes (v1.5.0+)

| Pipe | When | Script |
|------|------|--------|
| EOD emit | eod-shutdown | `scripts/eod-vault-emit.py` |
| TODO vault query | session-start | `scripts/session-vault-todo-query.py` |
| CI failure emit | red CI / manual | `scripts/vault-emit-ci-failure.py` |

## Relation to LLM Wiki

- **Vault** = machine ledger (integrity, compound graph, scrubbed lessons).
- **Wiki** = human-navigable synthesis pages (Karpathy layer).
- Accepted wiki ingests should **dual-write** a vault event when `wiki_policy.dual_write_vault: true`.

## Security notes from guide

- Scrub at emission; never execute vault lessons as shell.
- L1 synthesis is report-only.
- Secrets must not enter the ledger.
